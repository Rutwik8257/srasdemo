# Client-First Showcase

Build a high-performance, visually stunning company website prototype using React.js that is designed to attract and impress potential business clients. The website should feel professional, modern, and trustworthy.

---

## Project Requirements

### Tech Stack
- **React.js** (with functional components and hooks)
- **React Router** for navigation
- **CSS Modules or Tailwind CSS** for styling
- **Framer Motion** for smooth animations
- **Lazy loading & code splitting** for performance optimization

---

### Performance Requirements
- Implement **React.lazy()** and **Suspense** for code splitting
- Use **useMemo** and **useCallback** to prevent unnecessary re-renders
- Optimize all images with proper sizing and lazy loading (`loading="lazy"`)
- Minimize bundle size — avoid unnecessary dependencies
- Use **React.memo** where applicable for component optimization
- Ensure the site is capable of handling high traffic by keeping the frontend stateless and lightweight

### Design Guidelines
- **Color Palette:** Use a professional palette — deep navy blue, white, and a vibrant accent color (e.g., electric blue or gold) to convey trust and authority
- **Typography:** Clean, modern fonts — use Google Fonts (e.g., Inter, Poppins, or Montserrat)
- **Spacing:** Generous whitespace to keep the layout breathable and premium
- **Responsive Design:** Fully mobile-first responsive across all screen sizes (mobile, tablet, desktop)
- **Micro-interactions:** Subtle hover effects, button animations, and scroll-triggered animations to enhance user experience
- **Consistency:** Maintain consistent padding, font sizes, and component styles throughout

---

### Additional Notes
- Use **placeholder content** (lorem ipsum or realistic dummy text) for all sections so the prototype looks complete and presentable
- Use placeholder images from **Unsplash URLs** or SVG illustrations
- All sections should be **smooth-scroll linked** from the navbar
- The overall feel should be **corporate, premium, and client-facing** — designed to convert visitors into leads
